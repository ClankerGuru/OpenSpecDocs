---
title: openspec view
description: Interactive dashboard for specs and changes
---

Displays an interactive dashboard showing spec counts and change progress at a glance.

## Usage

```bash
openspec view
```

## Features

- **Spec overview**: All capabilities with requirement counts
- **Change progress**: Visual progress bars for active changes
- **Archive history**: Recently completed changes

## Use Cases

### Quick status check

```bash
openspec view
```

### Before standup

See what's in progress and what's complete.

### Onboarding

Get a bird's-eye view of the project's specifications.

## Exit Codes

| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | Not an OpenSpec project |
